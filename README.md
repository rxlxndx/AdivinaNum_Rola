✓ El propósito del proyecto (juego interactivo para adivinar un número).
Hace un sistema que adivina el numero random del usuario

✓ Tecnologías utilizadas.
Python

✓ Instrucciones de uso.
1.-El programa debe indicar si el número ingresado es mayor o menor que el número
secreto.
2.-Al acertar, debe felicitar al usuario e indicar el número de intentos realizados.
3.- Debe usarse un menú interactivo donde el usuario decida si quiere jugar o salir del
programa.
